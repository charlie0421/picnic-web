N4큰 breadcrumb 전체를 버리는 대신 복사된 데이터와 기본 정보를 보존한다. 초과 부분은 [Truncated]로 표시한다. 객체에는 _truncated 표시를 남긴다.값 10,000개와 깊이 40 제한을 유지한다. 기본 category·type·level·timestamp·message를 먼저 복사한다. 복사 결과에 기존 scrubber를 적용한다. 원본 객체와 getter를 변경하거나 호출하지 않는다.

검증 중 발견한 사항

  • 첫 브라우저 검증의 SVG paint 참조 검사가 실패했다. blockAllMedia가 SVG 내용 자체를 기록하지 않기 때문이다. 이 설정을 유지했다. SVG 참조 보존은 단위 테스트로 검증하고, 브라우저에서는 기록되는 CSS declaration의 내부 참조를 검증했다. SVG 내용 차단도 확인했다.
  • 전체 테스트를 브라우저 fixture 설치 중에 병렬 실행해 __tests__/scripts/envelope-test-routes.test.ts의 “저장소의 app/ 에는 테스트용 라우트가 없다” 검사 1개가 실패했다. fixture 정리 후 순서대로 실행한 최종 전체 테스트는 통과했다.
  • ESLint CLI 직접 호출은 저장소가 legacy 설정을 사용해 flat config 탐색에서 실패했다. 저장소의 공식 npm run lint 명령은 통과했다.

유지되는 제한

  • SVG href 보존 대상은 확인된 use 노드다. 대상 정보가 없는 mutation과 다른 navigation 링크의 fragment는 제거한다. recording 간 노드 정보는 공유하지 않는다.
  • 내부 참조는 형식으로 제한한다. 실제 문서에 해당 ID가 존재하는지는 확인하지 않는다. 긴 ID, 점·공백·이스케이프가 있는 참조는 제거한다.
  • SDK가 CSS 참조를 절대 URL로 변환한 경우 그 URL의 fragment는 제거한다. 절대 URL이 동일 문서를 가리키는지 추정하지 않는다.
  • breadcrumb 제한은 값 개수·깊이와 복사 배열 크기에 대한 제한이다. 새 byte 제한을 추가하지 않았다. 불투명 객체는 기존 동작과 같이 SDK normalization에 맡긴다. 읽기·복사·정제 자체가 실패하면 breadcrumb를 버린다.
  • Replay의 8 MiB·2초·200,000개 값·깊이 80 제한, maskAllText·maskAllInputs·blockAllMedia 설정은 유지한다.
  • 검증은 합성 데이터와 로컬 수신기로 수행했다. 운영 Sentry 저장·after flush·fingerprint 도착 증거는 이번 작업으로 확보하지 않았다.

독립 리뷰 대기

Orca Run run_430662d02492의 최신 권한 검증에서 Claude read-only reviewer가 일반 Bash 명령을 실행할 수 있었다. 정확한 제한 권한을 보장하지 못하므로 review capability 차단을 유지한다. Codex IPC와 Gemini의 기존 차단도 유지한다. 별도 argv·직접 CLI·네이티브 하위 에이전트로 우회하지 않았다. 새 작업자를 생성하지 않았다.

차단이 해제되면 이번 diff·요구사항·관련 파일·검증 결과를 구현과 다른 공급자의 독립 리뷰어에게 전달해야 한다. 개인정보 정제 변경이므로 고위험 리뷰 조건을 유지한다. 이 보고서는 독립 리뷰 승인 증거가 아니다.
