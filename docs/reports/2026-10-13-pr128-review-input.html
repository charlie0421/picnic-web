PR #128 독립 리뷰 자료

2026-10-13 KST. 독자: 개인정보 처리 변경을 검토하는 독립 리뷰어. 목적: 요구사항, 정확한 코드 diff와 검증 결과를 제공한다.

리뷰 준비 완료. 독립 리뷰는 아직 시작하지 않았다. 실제 구현자는 Codex다. 다른 공급자의 Frontier 이상 리뷰가 필요하다. 리뷰 승인이나 머지 준비 완료를 뜻하지 않는다.

대상과 요구사항

PR #128은 OPEN·Draft다. 기준 커밋은 5a30718ddd09e94bff162677eb5c63931030e0cc, 원격 head는 1aa136366ed5bd7abbe7de20623684eaec0e111e다. 로컬 bb4acca269c6202a7f9cb43e41a3674843ea25c2의 실행 코드·테스트·설정은 원격 head와 같다.

  • F4: 이스케이프된 슬래시 경로의 query·fragment 유출을 차단한다. CSS 선택자와 색상은 보존한다.
  • N2: CSS 내부 참조와 확인된 SVG use 노드의 href·xlink:href를 보존한다. 허용 문법은 #[a-zA-Z_][a-zA-Z0-9_-]{0,63}이다. 외부 URL의 query·fragment는 제거한다. envelope 메타데이터는 SVG 노드 근거가 될 수 없다.
  • N4: 큰 breadcrumb에서 기본 정보와 정제된 복사 데이터를 보존한다. 초과 부분은 [Truncated]로 표시한다. 원본 변경·getter 호출 없이 값 10,000개·깊이 40 제한을 유지한다.
  • Replay의 8 MiB·2초·200,000개 값·깊이 80 제한과 maskAllText·maskAllInputs·blockAllMedia를 유지한다. 새 byte 제한, 녹화 활성화, 운영 설정 변경은 범위 밖이다.

리뷰 범위와 완료 조건

리뷰어는 아래 diff, 관련 원본 파일과 테스트를 읽는다. 정확성·회귀·개인정보 노출·경계 조건·테스트 공백을 확인한다. 지적에는 심각도, 파일·위치, 실패 조건, 최소 수정 방향을 제시한다. 알려진 제한과 새 회귀를 구분한다. 셸 테스트는 조정자에게 요청한다. 코드·설정·Jira 상태·원격 저장소를 변경하지 않는다. 최종 결과는 APPROVE 또는 REQUEST_CHANGES와 검증 한계를 포함한다.

제한: 내부 ID의 실제 존재 여부는 확인하지 않는다. 대상 정보 없는 mutation과 recording 간 SVG 참조는 보존을 보장하지 않는다. SDK가 절대 URL로 변환한 내부 참조는 fragment가 제거될 수 있다. 불투명 breadcrumb 객체는 기존 SDK normalization에 맡긴다. 결제 관련 예상 실패 6개는 이 diff의 범위 밖이다.
