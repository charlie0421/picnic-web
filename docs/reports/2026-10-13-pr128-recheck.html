요구사항과 범위

  • F4: 이스케이프된 슬래시 경로의 query·fragment 유출을 차단한다. CSS 선택자와 색상은 보존한다.

  • N4: 큰 breadcrumb에서 기본 정보와 정제된 복사 데이터를 보존한다. 초과 부분은 [Truncated]로 표시한다. 원본 변경·getter 호출 없이 값 10,000개·깊이 40 제한을 유지한다.
  • Replay의 8 MiB·2초·200,000개 값·깊이 80 제한과 maskAllText·maskAllInputs·blockAllMedia를 유지한다. 새 byte 제한, 녹화 활성화, 운영 설정 변경은 범위 밖이다.

F-1~F-5 수정 여부와 수정으로 생긴 회귀를 검토한다. 기존 일반 객체의 전체 키 열거, 불투명 객체의 SDK normalization 의존은 기존 제한이다. 내부 참조 대상의 실제 존재 여부는 검사하지 않는다. 대상 정보 없는 mutation, recording 간 SVG 참조, SDK가 절대 URL로 바꾼 내부 참조의 보존을 보장하지 않는다. 새로운 byte 제한과 운영 설정 변경은 범위 밖이다.

[F-1] Medium · 신규 회귀 · 개인정보 — lib/sentry/replay-scrub.ts:90
- 조건: 키 이름이 fill, stroke, filter, clip-path, mask 이면 위치와 무관하게 CSS 모드(비-opaque scrubCss)를 적용한다. 노드 attributes 인지, SVG 노드인지 확인하지 않는다. type 5 custom event payload 같은 일반 데이터에도 적용된다.
- 실패 입력: { type: 5, data: { tag: 'breadcrumb', payload: { data: { filter: String.raw`/callback\?code=secret-opaque` } } } }
- 결과(P2 실행): filter·mask·fill·stroke·clip-path 는 원문 `/callback\?code=secret-opaque` 가 그대로 남는다. 대조군 키 note 는 '' 이다.
- 회귀 근거: PR 이전에는 이 5개 키가 `/url\(|@import|\\/` 분기로 가서 opaque 모드가 '' 를 반환했다. CSS 모드는 이스케이프된 `?`·`#` 를 선택자 식별자로 취급한다(replay-scrub.ts:54 의 비-opaque 분기). F4 가 막으려는 입력 유형이 이 5개 키에서 다시 통과한다.
- 참고: 운영 설정 blockAllMedia 는 svg 를 차단한다(@sentry-internal/replay index.js:9676-9677, analyzer:78 단언). 그래서 SVG presentation 속성 경로는 현재 운영 녹화에서 보존 효과가 없고 노출 면만 늘린다.
- 최소 수정: 5개 키의 CSS 모드를 노드 attributes 봉투 안으로 한정한다. 가능하면 isSVG===true 노드 또는 같은 recording 에서 확인된 SVG 노드 id 로 더 좁힌다. 그 밖의 위치는 기존 opaque 경로를 유지한다. 위 입력의 테스트를 추가한다.

[F-2] Medium · F4 잔여 누출(PR 이전에도 누출, 신규 회귀 아님) · 개인정보 — lib/sentry/replay-scrub.ts:54
- 조건: 이스케이프된 슬래시를 가진 식별자 바로 앞 문자가 `.` 또는 `#` 이면 remainder 에 'identifier' 를 넣는다. 다른 슬래시가 없으면 stripUrlQueries 가 fragment 를 자르지 않는다.
- 실패 입력(P1 실행, opaque 문자열 data.payload.message):
  · `example.com\/callback#secret-opaque` → 원문 유지
  · `..\/callback#secret-opaque` → 원문 유지
  · `.\/callback#secret-opaque` → 원문 유지
  · 대조군 `callback\/path#secret-opaque` → ''
- 범위: `?` 는 remainder 검사(replay-scrub.ts:81)가 막는다. `#키=` 형태도 QUERY_PAIR 가 막는다. 남는 것은 `키=` 형태가 아닌 fragment 다.
- 판단: 요구사항 F4 는 "이스케이프된 슬래시 경로의 query·fragment 유출 차단"이다. 이 입력은 리뷰 자료의 제한 목록에 없다.
- 최소 수정: `.`·`#` 예외를 적용한 식별자 뒤에서 선택자 구분 문자(공백, `{`, `,`, `>`, `+`, `~`, `)`)보다 먼저 `#` 를 만나면 '' 를 반환한다. `.w-1\/2{width:50%;color:#fff}` 는 `#` 가 `{` 뒤에 있으므로 보존된다. 위 3개 입력을 it.each 표에 추가한다.
- 대안: 사용자가 이 입력을 허용 제한으로 결정하면 제한 목록에 명시한다. 그 결정 없이는 승인하지 않는다.
