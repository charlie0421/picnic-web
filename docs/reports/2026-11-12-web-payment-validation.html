개방 전 미해결 항목

  • Origin 실측: 구체적인 환경·계정 사용과 요청 실행 승인을 받은 뒤 Vercel Preview 및 Production의 www.picnic.fan 동일 origin POST와 picnic.fan 리디렉트 후 요청을 확인한다. Next의 로컬 next start URL 동작이나 단위 시험을 이 증거로 대체하지 않는다. 아직 실제 도메인 요청을 보내지 않았다.
  • 경고 관측: business 503에는 의도한 CLOSED와 open 환경의 잘못된 정책 설정이 함께 들어간다. Sentry error가 없다고 정상으로 판단하면 안 된다. 조정자는 개방 전 payment.order.business.unavailable WARN의 별도 운영 경보 경로를 확정·검증하는 것을 선행 조건으로 정했다. 경보 구성이나 전달 시험은 아직 하지 않았다.
  • JSON 중복 key는 마지막 값으로 검증하며 getUser timeout은 플랫폼 상한에 의존한다. 기존 범위 밖 nit로 유지한다. 실제 DB/PostgREST 서버·UI·청구 어댑터·공급자/credential·Edge·배포·판매 개방은 미검증이다.
  • 기존 T4 Low2, Supabase 원본 권한 거부의 연결 종료와 부분 probe 비동등성, 웹 refund_abuse CHECK의 감사 누락 경고, 기준 SQL26실패는 이 단위의 통과로 해결되지 않는다.

아직 확인하지 않은 것

실제 PostgREST·공급자·운영 결제 E2E는 실행하지 않았다. id::text 응답 키, NULL composite, STABLE RPC GET과 실제 권한을 격리 환경에서 시험해야 한다. 기존 staging은 최신 migration·cron 목적지의 확인이 필요하다. PortOne LIVE는 현재 DB의 저장 구분이며 실제 운영 채널임을 증명하지 않는다.

과거 platform=web은 현재 API에서 404가 된다. T7은 이를 미결제로 표시하지 않는다. T6의 비스냅샷 종결 SUCCEEDED, T4의 totals/orderId 확장과 실제 배분 조회는 후속 계약이다. 영수증이 없거나 UNKNOWN이라고 해서 미청구를 뜻하지 않는다. 읽기 전용 결과는 웹훅·대사를 대신하지 않는다.
