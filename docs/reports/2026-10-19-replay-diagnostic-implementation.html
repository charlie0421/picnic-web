판단 기록

  • 후보 캡처는 합성 브라우저에서 Worker 입력을 관찰해 파일로 저장한다. 운영 수집 경로를 우회하거나 외부로 보내지 않는다. 인증 미확정 시험은 해당 합성 문서의 getUser에 실패 응답을 주입한다. 팝업은 실제 /api/popups 응답, SPA는 /ko/faq에서 동일 문서 이동으로 시험했다.
  • 중지 후 사라지는 진단 패널의 중지 버튼은 재생 화면과 의도적으로 다르다. 레이아웃 비교는 제품 버튼을 비교하며, 진단 패널·번호 텍스트 마스킹은 별도 projector·브라우저 assertion으로 확인한다.
  • 합성 런타임은 두 loopback 포트만 연결한다. 기존 harness대로 빌드 중 Google Fonts의 두 공개 호스트만 허용해 운영 CSS와 같은 자산을 만들었다. 템플릿 갱신 후 기존 로컬 CSS manifest의 내용은 동일했다.
