CI 첫 기록 실패 후속 수정

합성 브라우저에서 같은 실패를 재현했다. Worker가 schema를 반환했으며, 저장한 합성 입력을 같은 projector로 검사하자 engine/nodes.ts가 임시 template 태그를 거부했다. 해당 노드는 숨겨진 React 스트리밍 영역 div hidden id="S:4" 안에 있었고 다음 mutation에서 영역 전체가 제거됐다. 페이지 load 완료만으로 React의 임시 영역 제거를 보장할 수 없었다.
