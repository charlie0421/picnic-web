PR 5 — 브라우저 로그 개인정보 검증

기준: 2026-10-07. 리뷰 수정 커밋 c4730082, 기준 브랜치 edac2583. 독립 리뷰 진행 중이며 아직 머지·배포하지 않았다.

변경

브라우저 오류·breadcrumb·transaction·span에 공통 URL 가림을 연결했다. 기존 서드파티 오류 필터·표본율·Replay 지연 로드는 유지했다. 운영 Replay 환경변수는 변경하지 않았다.

Sentry 9.47.1의 Replay DOM 기록은 beforeAddRecordingEvent를 거치지 않는다. Replay는 transport를 직접 호출한다. 전송 경계에서 Replay metadata와 녹화 데이터를 함께 정제한다. 압축 기록은 segment header와 zlib 본문을 분리하고, 정제 후 다시 압축한다. 원본 envelope를 수정하지 않으며 UTF-8 바이트 길이를 다시 계산한다.

npx playwright install chromium

브라우저 검사는 로컬 Supabase fixture와 Sentry 수집기를 사용한다. Replay CDN 요청은 lockfile과 같은 SDK recorder bundle로 응답한다. 외부 브라우저 요청은 차단하고, 실제 수신 envelope를 압축 해제하여 검사한다. 테스트 페이지는 빌드 중에만 app/api/envelope-test/browser에 복사한다. 브라우저 검사와 전체 단위 테스트는 동시에 실행하지 않는다.

제한과 후속 확인

  • 녹화 입력과 압축 해제 결과는 각각 최대 8MiB다. 압축 스트림과 객체 순회는 2초 deadline을 적용한다. 동기 JSON 처리 구간을 선점하지는 않는다. 객체 깊이는 80, 순회 노드는 200,000으로 제한한다. 정제 또는 압축에 실패하면 해당 Replay envelope를 버린다.
  • Tailwind 선택자 escape는 보존한다. URL·문자열 토큰 안의 지원하지 않는 escape는 해당 토큰을 비운다. 구조를 판별하지 못한 CSS는 스타일을 비운다. query/fragment를 포함한 srcset·imagesrcset과 srcdoc도 비운다. 일부 Replay 표시 정보가 줄어들 수 있다.
  • 운영 Replay 활성화, 운영 Sentry Data Scrubber 확인, 실제 운영 오류 수신·fingerprint 검증은 이번 로컬 브라우저 검사의 성과로 주장하지 않는다.
  • 브라우저 envelope 검사는 로컬에서 수행한다. GitHub CI는 타입·lint·단위 테스트를 실행한다. SDK 또는 수집 설정 변경 시 브라우저 검사를 다시 실행해야 한다.

리뷰 지적 처리

지적처리
B1 · Tailwind CSS 소실선택자 escape를 보존하고 URL 토큰을 따로 처리했다. 실제 브라우저에서 nonempty _cssText와 Tailwind 선택자 보존을 확인했다.
B2 · 호출자 데이터 변경breadcrumb의 plain object·배열을 제한된 깊이로 복사한다. 원본 콘솔 인수·fetch 자료를 변경하지 않는다. 순환 참조와 getter도 테스트했다.
M4 · 동적 CSSisStyle, rule/replace/replaceSync, 스타일 선언과 CSS 문자열을 정제한다. 7종 record의 단위 테스트와 실제 CSS rule/declaration 기록을 검증했다.
L5 · 상대 URL 속성formaction·cite·background·longdesc·manifest·usemap·object data와 imagesrcset을 보완했다. 그 밖의 비표준 속성은 기존 문자열 휴리스틱을 적용하며, slash와 key=value가 없는 불명확한 값의 분류는 후속이다.
L7·L9 · tripwire·Unicodebreadcrumb의 tripwire를 오류/transaction 태그로 올린다. Unicode 길이가 달라져도 CSS URL 위치가 어긋나지 않도록 토큰 기준으로 처리한다.
M3 · 큰 DOM / L6 · SVG fragment / L8 · 메모리비차단 후속으로 남긴다. 큰 기록은 기존 제한에서 버리고, fragment는 정책대로 제거한다. SVG 참조가 줄어들 수 있다. Replay 활성화 전에 실제 화면의 크기·깊이·메모리를 측정해야 한다.

리뷰 지적을 재현한 테스트 13개가 수정 후 통과했다. 실제 브라우저 검사에서 콘솔 객체 보존, 동적 CSS, Replay custom breadcrumb·performanceSpan 수신도 확인했다.
