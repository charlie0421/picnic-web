실행 장애와 재개 조건

검증된 정확한 argv로 Orca 터미널 생성 3회를 시도했으며, 최초 및 최종 시도는 Timed out waiting for terminal handle after creation, 중간 시도는 The Orca runtime closed the connection before responding를 반환했다. 실제 작업자 모델 호출이 성공한 것으로 간주하지 않았다.

중간에 Orca 실행 중 아님을 확인하고 공식 orca open으로 복구했다. 런타임은 1.4.220에서 1.4.222로 바뀌었고 최신 가이드를 다시 읽었다. 복구 후에도 생성 시간 초과가 반복됐다. 실행 재시도 2회를 사용했으므로 동일 세션에서 추가 생성이나 새 Run을 통한 우회는 하지 않는다. 구독 소진으로 분류하거나 공급자를 임의 변경하지 않는다.

Orca 터미널 생성 장애를 해결하고, 기존 Run·시도 기록·계정 바인딩·providerHold·재시도 예산을 확인해야 한다. 재개 직전 사용량·capability·build-launch를 새로 확인한다. 인증·개인정보 변경은 다른 공급자의 독립 리뷰를 유지해야 하므로 이를 생략해 PR을 완료 처리하지 않는다.
