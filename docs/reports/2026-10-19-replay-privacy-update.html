1. 확인한 사실과 변경 범위

항목확인 결과이번 처리
정책 원문한국어·영어 공개 방침 모두 제6조에서 모든 개인정보를 대한민국에 저장한다고 설명한다. Sentry·Replay 설명은 없다.제6조 수정안과 제2·3·5·7조 추가 문구를 작성했다. 제9조의 기존 권리는 유지한다.
데이터 출처getPolicy('privacy', lang)는 Supabase policy의 본문을 조회한다. 이 저장소에 한국어·영어 정책 원문 파일은 없다.화면에 별도 본문을 겹쳐 표시하지 않는다. 실제 게시 시 대상 행과 원문을 먼저 대조한다. DB 쓰기·마이그레이션은 실행하지 않았다.
적용 범위현재 방침은 웹과 앱 등 회사 서비스 전반을 설명한다. 이번에 확인한 구현은 picnic-web이다.추가 문구를 피크닠 웹의 기술 진단으로 한정한다. 앱 등 다른 소비자가 같은 정책 행을 쓰는지는 게시 전에 확인한다.
Sentry 저장 지역10월 19일 계정 점검에서 US 지역을 확인했다. 공식 문서는 선택 지역에 오류·성능 정보·Replay와 해당 백업을 저장한다고 설명한다.미국 전송·저장을 안내한다. 진단용 주소는 o<숫자>.ingest.us.sentry.io만 허용한다. 독일 또는 지역이 생략된 주소에서는 수동 진단을 허용하지 않는다.
보관확인한 Team 요금제의 오류·Replay 기본 보관은 90일이다. 같은 계정 응답의 유효 보관 설정은 원본 성능 스팬 30일, 성능 집계 지표 최대 396일이다.Replay의 90일을 모든 진단 데이터의 보관 기간으로 확대하지 않는다. 기존 자료에는 수집 시점의 기간이 적용될 수 있으므로 새 자료 기준임을 구분한다.
권리 행사현재 제9조는 삭제·처리정지·동의 철회 등의 권리를 설명한다. 제13조는 황재근·CX팀·앱 내 1:1 문의를 안내한다. 2026-10-19 사용자가 이 기존 안내는 현재도 유효하다고 확인했다.Replay 전용 삭제 요청 기능 보류를 일반 권리 포기로 표현하지 않는다. 검증되지 않은 이메일이나 404 주소를 새 접수 창구로 안내하지 않는다.
버전·날짜공개 화면 상단은 코드에서 버전 1.0과 조회 당일을 표시한다. 본문은 통합 V2.4·2024-06-04 시행이라고 적고 있다.오늘을 새 방침 시행일로 임의 지정하지 않는다. 게시 전에 실제 정책 버전·시행일과 화면 표시를 함께 정리한다.

일반 오류·성능·세션 진단은 Replay와 별도로 동작한다. 현재 코드는 오류·성능·세션 정보를 수집하고, 요청 본문·헤더·쿠키·URL 쿼리 등의 일부 필드를 제거한다. 이 정제만으로 모든 데이터가 익명이라고 단정하지 않는다. 기본 BrowserSession 통합과 합성 브라우저의 일반 session envelope 관측을 대조했다. 세션 정보의 보관 기간은 아직 확인하지 못했으며 게시 전 보완 조건이다. 직접 전송에서 Sentry가 받는 네트워크 IP와 최종 저장 필드도 구분한다.

2. 한국어 본문 수정안

아래는 기존 본문에 적용할 절별 문안이다. 다른 조항과 지역별 부칙은 그대로 유지하되 충돌 여부를 게시 전에 검토한다. 편집 지시와 이 문서의 검토 메모는 공개 본문에 넣지 않는다.

제2조 말미에 추가 — 웹 기술 진단 목적

피크닠 웹의 장애 확인 및 개선: 오류의 원인, 서비스 성능과 세션의 정상 작동 상태를 확인하고 개선하기 위해 기술 진단 정보를 처리합니다. 화면 문제 진단 기능이 제공되는 경우, 이용자가 동의하고 시작한 한국어 공개 투표 목록(/ko/vote)의 화면 배치·스크롤·배너 동작을 확인하는 데 Sentry Replay를 사용합니다.

제3조에 추가 — 웹 기술 진단 항목

일반 오류·성능·세션 진단: 웹 이용 중 오류와 성능을 확인하기 위한 오류 유형·내용·발생 위치·시각, 서비스 버전, 페이지 주소, 응답 시간, 브라우저·운영체제·기기 정보 및 진단 식별자 등 기술 정보가 처리될 수 있습니다. 일반 오류 이벤트에는 이전 화면 이동과 요청 주소(쿼리 제거), 콘솔 경고·오류 등의 정제된 진단 이력이 포함될 수 있습니다. 화면 녹화와 별도로 세션 식별자·상태·시작 및 보고 시각·오류 수·서비스 버전·실행 환경·브라우저 정보 등 정상 작동 상태를 확인하는 세션 정보도 전송합니다. 전송 전에 요청 본문·헤더·쿠키·URL 쿼리 등 일부 정보를 제거하거나 가립니다. 브라우저가 Sentry에 직접 연결할 때에는 네트워크 통신에 필요한 IP 주소와 브라우저 정보도 전달됩니다.

선택형 화면 문제 진단: 기능이 제공되는 경우 PC Chrome의 비로그인·광고 거절 이용자가 한국어 공개 투표 목록(/ko/vote)에서 안내를 확인하고 동의한 뒤 시작할 수 있습니다. 한 문서에서 한 번, 최대 60초 동안 화면 구조·포인터·휠 스크롤·배너 움직임과 진단 식별자·발생 시각 등 기술 정보를 기록합니다. 텍스트와 입력값은 가리고 이미지·영상은 차단합니다. 저장되는 브라우저·운영체제·기기 항목은 시작 전 안내에 표시합니다. 직접 전송 과정에서는 IP 주소와 브라우저 정보도 Sentry에 전달됩니다. 일반 방문자의 화면을 자동으로 녹화하지 않습니다.

화면 진단용 기록에는 계정 ID·이메일, 실제 페이지 주소의 원문, 네트워크 본문·헤더·콘솔 원문을 넣지 않습니다. 이는 화면 진단용 기록의 범위이며 일반 오류·성능·세션 정보와 동일한 수집 범위라는 뜻은 아닙니다.

제7조 말미에 추가 — 기술 진단 자료 보관

제9조 말미에 추가 — 선택형 진단과 권리의 관계

현재 화면 문제 진단에는 별도의 삭제 요청 접수 기능을 제공하지 않습니다. 이는 이 방침과 관계 법령에 따른 개인정보 관련 권리를 제한하거나 포기하게 하는 조건이 아닙니다. 진단 번호는 해당 기록을 찾는 식별자이므로 공개 게시하지 마십시오.

Add to Article 2 — Technical diagnostics

Web service diagnostics and improvement: We process technical information to investigate errors and improve service performance and session stability. When the optional screen diagnostic feature is available, we use Sentry Replay to investigate layout, scrolling, and banner problems on the public Korean vote list (/ko/vote) after the visitor consents and starts the diagnostic.

Add to Article 3 — Web diagnostic information

Error, performance, and session diagnostics: Technical information may include error types and messages, code locations and timestamps, service versions, page addresses, response times, browser, operating system and device information, and diagnostic identifiers. Error events can include scrubbed diagnostic history, such as earlier navigation and request addresses with query parameters removed, and console warnings and errors. Separately from screen recordings, we also send session information to monitor stability, including session identifiers, status, start and reporting timestamps, error counts, service versions, runtime environments, and browser information. We remove or mask some information before transmission, including request bodies, headers, cookies, and URL query parameters. When the browser connects directly to Sentry, Sentry also receives the IP address and browser information needed for network communication.

Optional screen diagnostics: When available, visitors using desktop Chrome who are signed out and have rejected advertising can read the notice and consent on the public Korean vote list (/ko/vote). A diagnostic can start once per document and record for up to 60 seconds. It records screen structure, pointer movement, wheel scrolling, banner movement, diagnostic identifiers, timestamps, and technical information. Text and input values are masked, and images and video are blocked. The notice lists the browser, operating system, and device fields that are stored. Direct transmission also delivers the IP address and browser information to Sentry. We do not automatically record ordinary visitors' screens.

Screen diagnostic records do not include account IDs, email addresses, the original actual page address, or original network bodies, headers, or console content. These limits apply to screen diagnostic records and do not describe the same collection scope as error, performance, and session diagnostics.

4. 게시 전에 확정할 사항

본문 수정안과 동의 화면 보완만으로 법률 적합성이나 국외 이전의 적법한 근거가 확정되는 것은 아니다. 현재 사용하는 수탁 계약과 국외 이전 근거, 실제 권리 행사 절차를 담당자가 확인해야 한다.

  1. 제13조의 황재근·CX팀·앱 내 1:1 문의는 2026-10-19 사용자가 현재도 유효하다고 확인했다. 로그아웃한 웹 방문자도 이 경로로 권리를 행사할 수 있는지는 별도로 확인한다. Replay 전용 접수 기능을 새로 만들거나 검증되지 않은 주소를 대신 넣지 않는다.
  2. 일반 오류·성능·세션 진단과 선택형 Replay 각각의 처리·국외 이전 근거, 실제 적용 계약, 고지·동의 방식을 확인한다. 현재 진단 시작 버튼 하나가 법에서 요구하는 별도 동의를 충족한다고 단정하지 않는다. Sentry의 공개 DPA 문서를 읽었다는 사실을 해당 계정의 계약 체결 증거로 사용하지 않는다.
  3. 세션 상태 정보(Release Health)의 실제 보관 기간을 확인한 뒤 한국어·영어 제6조 보관 표에 추가한다. 공식 API가 90일 조회 예시를 제공한다는 사실만으로 실제 보관 기간을 90일로 단정하지 않는다. 이 확인 전에는 초안을 게시하지 않는다.
  4. 진단 외 개인정보(DB·호스팅 등)의 실제 저장 지역을 확인하고 제6조에 별도로 기재한다. 현재의 모든 데이터 국내 저장 문구를 대체하면서 다른 처리의 지역 안내를 빠뜨리지 않는다.
  5. 운영 진단용 DSN이 명시적 .ingest.us.sentry.io 형식인지 비밀값을 노출하지 않는 읽기 전용 점검으로 확인한다. 지역이 생략된 기존 DSN은 진단을 허용하지 않는다. 공유 NEXT_PUBLIC_SENTRY_DSN을 변경하면 일반 SDK에도 적용되므로 별도 영향 확인 없이 바꾸지 않는다.
  6. 새 방침의 버전·시행일·사전 안내 방법을 결정한다. 화면의 임시 버전과 조회 당일 표시를 실제 정책 정보에 맞추거나 제거하는 변경을 함께 검토한다.
  7. 운영 DB에서 한국어·영어 대상 행의 ID·현재 본문·버전·수정 시각·삭제 여부와 사용처를 읽기 전용으로 대조한다. 원문 백업과 정확한 변경 전후 비교를 만든 뒤 게시 승인을 받는다. 원문이 바뀌었거나 중복 행이 있으면 덮어쓰지 않는다.
  8. 게시 후 한국어·영어 공개 페이지, 영어 이외 언어에서 표시되는 한국어 fallback, 영향을 받는 소비자에서 본문·버전·시행일을 확인한다. 이 게시와 Replay 활성화는 별도다. 실제 새 Replay의 저장 필드·연속 재생·삭제·OFF 배포 확인 등 기존 운영 조건은 유지한다.

서비스명 “피크닠”은 확인한 현재 한국어 정책 본문의 표기를 유지했다. 사이트 메타데이터의 “피크닉”과 다르므로 정책 게시 때 서비스명 표기를 함께 대조한다. 현재 방침의 다른 수탁 업체·다른 국가·앱 수집 항목·지역별 부칙 전체를 감사한 결과는 아니다. 이번 문안으로 서비스 전체 고지의 완전성을 주장하지 않는다. 삭제 요청 기능 보류가 기존 권리 조항과 모순되지 않도록 실제 처리 절차의 확인을 남겨 둔다.

5. 구현·검증 상태

동의 전에 수신 업체, 미국 전송·저장, 업체 연락처, 동의 후 HTTPS 전송, 취소해도 공개 목록을 이용할 수 있다는 점을 표시하도록 보완했다. 별도 삭제 요청 접수 기능은 추가하지 않았다. 미국이 명시되지 않은 진단용 DSN은 거부한다. 직접 전달한 endpoint도 transport에서 다시 검사한다. 일반 Sentry transport와 오류 수집 설정은 바꾸지 않았다.

지역 검사와 안내의 회귀 시험을 먼저 실행해 예상 실패 3건을 확인했다. 구현 후 관련 시험 23개 파일·214개가 통과했다. 최초 구현의 전체 단위 시험 5,454개 통과·예상 실패 2개·건너뜀 1개, 타입·린트 검사, 합성 브라우저 19개 시나리오와 배포 파일 281개 검증이 통과했다. 리뷰에서 확인한 transport 지역 검사도 실패 시험 2개로 재현하고 수정했다. 수정 후 관련 3개 파일·56개, 전체 단위 시험 5,456개·예상 실패 2개·건너뜀 1개, 타입·린트 검사가 통과했다. 최종 빌드 ddkaiLEuWM1n3aTlBl0MO에서도 합성 브라우저 19개와 배포 파일 281개 검증이 통과했다. 1280×900 화면에서 동의 문구와 버튼 표시, 동의 전 Replay 전송 0건, 취소 동작을 확인했다. 이 문서는 PC·모바일 폭에서 표시를 확인했다. Claude Opus 5.5 / high 독립 리뷰와 같은 리뷰어의 재검증에서 APPROVE를 받았다. 최초 Medium 2·Low 5 중 5건은 수정했고 2건은 근거로 해소했다. 참고 의견의 언어 fallback도 반영했으며 미해결 항목은 0건이다. 리뷰어 본인의 완료 보고가 수락됐고 작업 터미널·임시 파일을 정리했다. 이 결과는 코드·문서 검토이며 법률 적합성, 운영 게시·배포·활성화 승인이 아니다. 원격 CI의 최종 커밋 결과는 PR #144 checks에서 확인한다. DB 쓰기, 운영 설정 변경, 병합·배포·활성화, 실제 Replay 업로드·삭제는 수행하지 않았다.
