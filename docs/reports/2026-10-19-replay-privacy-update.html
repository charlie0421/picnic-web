Sentry DPA 5.1.0 — 2026-10-20 수락 완료

사용자에게 회사 명의의 계약 수락 의미와 권한 확인 조건을 설명한 뒤 진행 승인을 받았다. 기존 Icon Casting 조직(icon-casting)의 계약 버전이 5.1.0임을 재확인하고 I Accept를 실행했다. 서버의 consent.acceptedVersion은 5.1.0, createdAt은 2026-10-20T01:13:29.771197Z(10:13:29 KST)로 저장됐다. 새로고침 후 화면의 Version 5.1.0 signed Oct 20, 2026 표시도 확인했다. 수락 전후 정책 응답에서 변경된 항목은 DPA 하나였다. 계정 식별 정보가 포함된 원문은 제한 권한 로컬 디렉터리에 보관했다.

수락 전 이력: 10월 19일 23:54 KST의 조직 정책 API 응답은 200이었다. DPA 버전은 5.1.0이고 consent는 null이었다. 조직 법률 화면에도 Review and Accept가 표시됐다. hasSignature=true만으로 실제 수락을 뜻한다고 해석하지 않았다. 계정에 연결된 문서 주소는 DPA 5.1.0 — 2024-05-29로 연결됐다.

당시 계정 화면과 응답에는 전자 수락의 증거가 없었다. 별도로 서명한 계약이 있을 수 있으므로 미체결로 단정하지 않았고, 담당자에게 별도 기록의 유무를 확인 요청했다. 이번 수락은 새 전자 수락 기록을 확인한 것이며 과거 별도 계약의 존재 여부를 판정한 것은 아니다. 공식 수락 안내는 조직 Owner 또는 Billing 권한으로 수락할 수 있고, 서명본이 필요하면 DocuSign을 사용할 수 있다고 설명한다.

수락 전에 검토한 주요 조건은 다음과 같다. 이는 원문의 요약이며 법률 적합성 판정은 아니다.

  • 수락자는 고객을 구속할 권한이 있음을 확인한다. 고객은 처리 지시와 제공 데이터의 적법성을 책임지고 민감정보 전송 제한을 준수해야 한다.
  • Sentry의 보안·사고 통지·권리 행사 지원 의무와 고객의 보안·통지 책임을 구분한다. 일부 지원·감사 비용은 고객에게 발생할 수 있다.
  • 미국 및 재수탁 업체의 처리 지역, 재수탁 업체 변경 통지·이의 절차를 포함한다. 실제 설정의 저장 지역과 계약상 허용 범위는 같은 개념이 아니다.
  • 삭제·반환과 계약 종료 후 처리는 계약 조건 및 법적 보존 예외를 따른다. 이 DPA는 Release Health 세션에 특정 보관 일수를 제시하지 않으며, 한국 이용자의 국외 이전 근거까지 확정하지 않는다.
  • 같은 사항에 관한 기존 데이터 처리 부속 계약을 대체한다. 기본 계약의 책임 제한은 유지하되 유럽 개인정보 보호법·표준계약조항에 따른 정보주체 권리에 대한 예외를 둔다. 별도 서명본의 존재 여부는 확인되지 않았으며 과거 계약과의 개별 대조는 수행하지 않았다.

DPA 전자 수락은 완료했다. 국외 이전 근거·고지 방식, 비로그인 권리 행사 절차와 세션 보관 기간 등 게시 조건은 별도로 남는다. 운영 Replay는 OFF다.

Vercel — 현재 Pro의 런타임 로그 보관 1일

운영 배포가 속한 동일 팀을 조회해 Pro 요금제를 확인했다. Observability Plus 설정 조회는 404와 Observability Plus is not enabled를 반환했다. 일반적인 404만으로 기능 상태를 추정한 것이 아니다. 같은 팀의 /v1/drains, /v1/log-drains, /v2/integrations/log-drains GET 결과는 각각 0개였다.

이 계정 상태와 공식 런타임 로그 보관 표를 대조하면 현재 적용되는 문서상 기간은 1일이다. Observability Plus의 30일을 적용하지 않았다. 1일은 런타임 로그의 관측·보관 한도이며 모든 캐시·빌드 로그·백업의 삭제 시한을 뜻하지 않는다. 로그 전달 설정 0개도 애플리케이션이 직접 사용하는 Sentry 등 다른 전송 경로의 부재를 뜻하지 않는다.

Vercel 공개 DPA는 Pro·Enterprise 계약의 일부가 되며, 미국의 주 처리 시설과 Vercel·재수탁 업체의 다른 처리 지역을 설명한다. 이 일반 조건만으로 현재 서비스의 모든 개인정보·캐시·백업이 저장되는 국가나 기간을 확정하지 않는다. 진단 외 데이터의 항목별 고지 확인은 계속 필요하다.

10월 19일 조회에서는 계약 수락이나 설정 변경을 하지 않았다. 10월 20일 DPA 수락 시에도 요금제·결제·로그 전달 설정 변경과 지원 요청 전송은 하지 않았다. 계정 응답 원문은 제한 권한 로컬 디렉터리에 보관하고 이 문서에는 필요한 결론만 기록했다.

  2. 일반 오류·성능·세션 진단과 선택형 Replay 각각의 처리·국외 이전 근거, 실제 적용 계약, 고지·동의 방식을 확인한다. 현재 진단 시작 버튼 하나가 법에서 요구하는 별도 동의를 충족한다고 단정하지 않는다. Sentry 조직의 DPA 5.1.0은 2026-10-20 전자 수락을 완료했고 계정의 서버 기록과 화면으로 확인했다. 이 계약 수락만으로 각 처리·국외 이전의 근거와 고지 조건이 충족됐다고 판정하지 않는다.
  3. 세션 상태 정보(Release Health)의 실제 보관 기간은 계정 API 재조회에서도 확인되지 않았다. 사용자 지시로 공급자 문의는 진행하지 않는다. 공식 API의 90일 조회 예시나 Replay의 90일을 이 자료의 보관 기간으로 대신 적지 않는다. 보관 기간 미확인 사항을 남겨 두며, 문의 중단을 방침 게시 승인으로 해석하지 않는다.
  4. 확인한 Supabase 서울 기본 리전과 Vercel 미국·한국·싱가포르 배포 리전을 출발점으로 진단 외 개인정보의 처리·저장 지역, 캐시·로그·백업의 범위와 기간을 확인하고 제6조에 별도로 기재한다. Vercel Pro·Observability Plus 미사용 상태의 런타임 로그는 공식 표상 1일, 확인한 Supabase Pro의 로그는 공식 기준 7일이다. Supabase는 PITR 미사용·완료된 일일 물리 백업 7개·조회 응답의 서울 리전을 확인했고, 공식 일일 백업 7일 기준과 대조했다. 모든 복제본의 위치·물리적 삭제 완료까지 확인한 것은 아니다. 다른 데이터의 기간은 별도 확인한다. 현재의 모든 데이터 국내 저장 문구를 대체하면서 다른 처리의 지역 안내를 빠뜨리지 않는다.
  5. 현재 공개 자산의 Sentry 주소는 명시적 미국 형식으로 확인했다. 새 진단 빌드의 DSN·최종 전송 주소·proof는 배포 전에 별도로 대조한다. 지역이 생략된 주소는 진단을 허용하지 않는다. 공유 NEXT_PUBLIC_SENTRY_DSN을 변경하면 일반 SDK에도 적용되므로 별도 영향 확인 없이 바꾸지 않는다.
  6. 새 방침의 버전·시행일·사전 안내 방법을 결정한다. 화면의 임시 버전·조회 당일 표시는 작업 브랜치에서 제거했다. 이 화면 수정은 방침 본문 개정이나 시행일 결정이 아니다.
  7. 운영 DB의 한국어·영어 대상 행과 원문 백업을 확보했고 앱의 공통 테이블 사용도 확인했다. 게시 직전 원문 해시·행 수·메타데이터를 다시 비교한다. 남은 조건을 반영한 전체 본문의 정확한 변경 전후 비교를 만든 뒤 게시 승인을 받는다. 원문이 바뀌었거나 중복 행이 있으면 덮어쓰지 않는다.
  8. 게시 후 한국어·영어 공개 페이지, 영어 이외 언어에서 표시되는 한국어 fallback, 영향을 받는 소비자에서 본문·버전·시행일을 확인한다. 이 게시와 Replay 활성화는 별도다. 실제 새 Replay의 저장 필드·연속 재생·삭제·OFF 배포 확인 등 기존 운영 조건은 유지한다.

서비스명 “피크닠”은 확인한 현재 한국어 정책 본문의 표기를 유지했다. 사이트 메타데이터의 “피크닉”과 다르므로 정책 게시 때 서비스명 표기를 함께 대조한다. 현재 방침의 다른 수탁 업체·다른 국가·앱 수집 항목·지역별 부칙 전체를 감사한 결과는 아니다. 이번 문안으로 서비스 전체 고지의 완전성을 주장하지 않는다. 삭제 요청 기능 보류가 기존 권리 조항과 모순되지 않도록 실제 처리 절차의 확인을 남겨 둔다.

5. 구현·검증 상태

후속 점검과 승인된 DPA 수락의 사실·근거·남은 조건을 문서에 추가했다. 한국어·영어 조항 수정안은 유지했다. 아래의 기존 Replay 시험·독립 리뷰와 10월 20일 화면 수정 검증을 구분한다.

2026-10-20 개인정보처리방침 화면 수정

상단의 고정 버전 1.0과 조회 당일을 최종 업데이트일로 표시하는 코드를 제거했다. 정책 본문과 본문 안의 버전·시행일은 유지한다. 404가 발생하던 /contact 링크는 사용자가 유효하다고 확인한 앱 내 1:1 문의 안내로 교체했다. 한국어·영어 안내를 모두 수정했다. 새 접수 기능이나 비로그인 접수 경로를 제공하는 변경은 아니다.

한국어·영어에서 날짜 변경 시 표시가 달라지는 문제와 기존 문의 안내의 문제를 시험으로 재현했다. 수정 후 회귀 시험 5개, 타입 검사와 변경 파일 린트 검사가 통과했다. 전체 단위 시험 261개 파일·5,461개 통과·예상 실패 2개·건너뜀 1개를 확인했다. 실제 페이지 컴포넌트와 시험용 정책 본문을 사용한 격리 Chromium에서 한국어·영어를 각각 390px·1280px 폭으로 확인했다. 본문 버전·시행일과 문의 안내가 표시됐고 가로 넘침이나 하단 링크는 없었다. 외부 요청은 차단했다. 이는 운영 DB 연동·배포 확인이 아니다. Claude Opus 5.5/high 독립 리뷰와 최종 재검증에서 APPROVE를 받았다. 실제 실행 인자의 모델·사고 수준과 읽기 전용 권한을 확인했고 리뷰어 본인의 완료 보고가 수락됐다. 코드 결함은 발견되지 않았다. 시험 결과 문서 반영 의견을 해결했다. 최종 리뷰의 Low 문서 배치 의견은 조정자가 반영하고 HTML 위치를 확인했다. 운영 검증 완료를 뜻하지 않는다. 운영 DB 본문, 정책 수정안, Replay 설정은 변경하지 않았다.

이전 Replay 구현 검증

동의 전에 수신 업체, 미국 전송·저장, 업체 연락처, 동의 후 HTTPS 전송, 취소해도 공개 목록을 이용할 수 있다는 점을 표시하도록 보완했다. 별도 삭제 요청 접수 기능은 추가하지 않았다. 미국이 명시되지 않은 진단용 DSN은 거부한다. 직접 전달한 endpoint도 transport에서 다시 검사한다. 일반 Sentry transport와 오류 수집 설정은 바꾸지 않았다.

지역 검사와 안내의 회귀 시험을 먼저 실행해 예상 실패 3건을 확인했다. 구현 후 관련 시험 23개 파일·214개가 통과했다. 최초 구현의 전체 단위 시험 5,454개 통과·예상 실패 2개·건너뜀 1개, 타입·린트 검사, 합성 브라우저 19개 시나리오와 배포 파일 281개 검증이 통과했다. 리뷰에서 확인한 transport 지역 검사도 실패 시험 2개로 재현하고 수정했다. 수정 후 관련 3개 파일·56개, 전체 단위 시험 5,456개·예상 실패 2개·건너뜀 1개, 타입·린트 검사가 통과했다. 최종 빌드 ddkaiLEuWM1n3aTlBl0MO에서도 합성 브라우저 19개와 배포 파일 281개 검증이 통과했다. 1280×900 화면에서 동의 문구와 버튼 표시, 동의 전 Replay 전송 0건, 취소 동작을 확인했다. 이 문서는 PC·모바일 폭에서 표시를 확인했다. Claude Opus 5.5 / high 독립 리뷰와 같은 리뷰어의 재검증에서 APPROVE를 받았다. 최초 Medium 2·Low 5 중 5건은 수정했고 2건은 근거로 해소했다. 참고 의견의 언어 fallback도 반영했으며 미해결 항목은 0건이다. 리뷰어 본인의 완료 보고가 수락됐고 작업 터미널·임시 파일을 정리했다. 이 결과는 코드·문서 검토이며 법률 적합성, 운영 게시·배포·활성화 승인이 아니다. 원격 CI의 최종 커밋 결과는 PR #144 checks에서 확인한다. DB 쓰기, 운영 설정 변경, 병합·배포·활성화, 실제 Replay 업로드·삭제는 수행하지 않았다.
