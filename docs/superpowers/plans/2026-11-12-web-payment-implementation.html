결정 기록과 진행 근거

  • 사용자 환경 선택: 운영에 영향이 없으면 프로덕션, 위험하면 로컬. 프로덕션 PG15.8의 RLS·조회 RPC·원장과 활성 wallet 예약 작업 10개를 읽기 전용으로 확인했다. 실제 적립·환불·워커와 공유되는 변경 시험은 로컬 전용 DB에서 수행한다. 관측 범위와 한계를 참고한다.
  • 사전 대조 T1→T7: 기존 result는 상계 전 기본 지급량만 반환한다. 판단: T1은 baseRewards·프로모션의 확인된 gross만 제공하고 totals:null을 유지한다. T4가 실제 배분 기준 gross/debtOffset/net을 추가한다. 근거 없는 순증가 표시가 생기지 않도록 한다.
  • 사전 대조 T1→T3/T5: T1은 영수증 기반 과거 조회다. 서버 주문이 없는 행의 orderId는 null이다. 후속 주문 API를 이미 구현한 것으로 표시하지 않는다.
  • 사전 대조 T2→T4/T8: 최소 fixture는 전체 migration·확장 검증이 아니다. 같은 source hash의 PG15/17 계약 시험과 Supabase 전체 체인을 분리한다.
  • 사전 대조 T3→T6: 새로운 청구 허용과 기존 거래 복구의 권한을 분리한다. lease 만료·조회 실패는 미청구 증거가 아니다.
  • 사전 대조 T4→T7: 상품 보너스는 고정 지급, 프로모션은 조건부다. 총지급을 잔액 증가나 환불 없음으로 해석하지 않는다.
  • T1: 최초 46개 RED→GREEN, 전체 5,512개 통과·기존 예상 실패 2개·건너뜀 1개를 확인했다. 독립 리뷰의 Low 3건을 보완하고 대상 4파일 239개와 타입 검사를 통과했다. 검증 기록을 참고한다. 원 리뷰어 재검증과 전체 계획·운영 준비는 아직 완료가 아니다.

기존 작업·외부 조건

PICNIC-13/15는 T5/T8 심사·채널, 14/60은 T6/T7 약관·문의, 84는 T1/T7 이력, 3046은 T4/T6 공통 원장, 3068/3069는 T8 별도 QA, 2760은 T3/T4/T7 프로모션, 2664는 T7 계정 전환 반례에 연결한다. 과거 이슈 완료를 현재 실연동 성공으로 사용하지 않는다.

staging은 있으나 최신 지갑 계약·worker·cron 목적지의 격리 확인이 필요하다. 현재 공유 로컬 54322의 존재는 전용 시험 권한이 아니다. 신규 유료 환경은 아직 필요하다고 판단하지 않으며 외부 설정 변경은 구체안과 비용이 있을 때 별도로 다룬다.
