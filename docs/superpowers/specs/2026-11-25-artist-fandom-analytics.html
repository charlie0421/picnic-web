PICNIC · KPOP 대시보드

아티스트 팬덤 분석

인도네시아에서 성장하는 걸그룹을 발견한 브랜드 담당자가 그룹과 멤버의 팬 규모, 광고 참여, 구매 이력을 같은 기간과 국가 기준으로 살펴보는 화면 설계입니다.

시장 탐색에서 아티스트 상세로

검색

기존 시장 차트에 그룹명·멤버명 검색을 추가합니다. 공개 카탈로그의 한글·영문 등 등록된 이름을 검색합니다. 결과에는 그룹·개인 구분과 소속을 표시합니다. 동명이인은 대상 ID로 구분합니다.

상세와 활동 이력

그룹은 직접 투표와 멤버 합산을 전환하고, 멤버·솔로는 개인 기록을 봅니다. 국가와 7·30·90일 조건을 유지합니다. 기간 평균과 누계를 일·기간 추이와 함께 제공합니다. 각 지표에 자료 범위와 마지막 집계일을 표시합니다.

국가별 비교

선택 아티스트를 기준으로 국가별 팬 수, 구매 참여자, 유료 재화 기여량을 나란히 봅니다. 순위에 없는 아티스트도 검색할 수 있습니다. 공개할 수 있는 집계가 없으면 카탈로그 정보와 데이터 상태를 보여줍니다.

광고와 결제의 두 가지 집계 범위

두 범위를 나눠 보여주는 방식을 채택했습니다. 담당자는 같은 아티스트 상세에서 범위를 전환하고, 차트 제목과 내보내기에도 선택한 범위를 확인합니다.

팬덤의 앱 활동

기준은 이벤트 직전 30일에 해당 아티스트에게 투표한 팬입니다. 그 팬이 PICNIC 전체에서 완료한 광고와 검증된 결제를 집계합니다. 한 팬이 여러 팬덤에 속할 수 있으므로 팬덤별 구매액을 더해 앱 매출을 계산할 수 없습니다.

직접 연결된 캠페인

캠페인과 아티스트를 연결한 자료가 있어야 합니다. 그 캠페인의 노출·검증된 완료를 집계하고, 주문에도 추적 가능한 연결 근거가 있을 때만 구매를 집계합니다. 복수 아티스트 캠페인은 캠페인 전체에서 주문을 한 번 세고, 임의 매출 배분은 하지 않습니다.

앱 활동만 제공하면 빠르게 팬 수요를 볼 수 있지만 개별 캠페인의 성과를 구분하기 어렵습니다. 직접 연결만 허용하면 기존 팬의 활동 이력을 활용하기 어렵습니다. 두 범위의 수치는 서로 합산하지 않습니다.

지표와 시각화

분모와 집계 단위는 화면의 지표 설명에서도 확인할 수 있게 합니다.
화면 지표와 표시 방식 계산 기준 및 원천
팬덤 규모 등록 팬 수와 기간 순 투표자를 각각 표시합니다. 추이가 있으면 둘을 별도 선으로 표시합니다. 등록 팬은 집계 시점의 유효한 즐겨찾기 계정 수입니다. 그룹 즐겨찾기 자료가 없으면 멤버 즐겨찾기의 고유 합집합으로 이름을 붙입니다. 즐겨찾기 해제 시 행을 삭제하는 경로가 있어 과거 추이는 스냅샷을 쌓은 날짜부터 제공합니다. 순 투표자는 기간 내 유효한 투표를 한 고유 계정입니다.
투표·재참여 총 투표 수, 유료 투표량, 재참여율과 동일 길이의 직전 기간 대비 추이를 표시합니다. 총 투표 수는 유효한 투표량의 합입니다. 직전 기간의 고유 투표자 중 이번 기간에도 같은 대상에 투표한 비율을 재참여율로 사용합니다. 유료 투표량은 구매 원천이 확인된 재화의 사용량으로 정의합니다. 무상 지급 가능성이 있는 스타캔디 사용분은 ‘스타캔디 사용량’으로만 표시합니다. 구매 후 투표자는 별도의 인원 지표입니다.
광고 참여 고유 광고 시청자, 누적 시청 시간, 시청자 1인당 평균 시간을 표시합니다. 국가별 지도와 수치 표를 함께 제공합니다. 개인·그룹별 검증된 완료 이벤트에서 고유 사용자를 셉니다. 동일 노출의 재전송·추가 보상은 중복 제외합니다. 실제 재생 초를 측정한 세션에서만 누적 시간을 계산합니다. 평균의 분모는 시간이 측정된 고유 시청자입니다. 시간 측정 범위도 함께 표시합니다.
광고 지역 검증된 시청 시점 국가별 인원과 미확인 인원을 표시합니다. 시청 당시에 확인된 국가가 없으면 미확인으로 둡니다. 기존 프로필 국가로 계산한 도표가 필요하면 ‘팬의 프로필 시장’으로 별도 표시합니다.
유료 파급력 구매 참여자 수, 반복 결제율, 두 번째 결제까지 걸린 기간의 분포를 표시합니다. 운영 스토어의 적격 결제와 환불을 검증합니다. 선택 기간 내 서로 다른 적격 결제가 2건 이상인 사람 ÷ 기간 내 구매자 수가 반복 결제율입니다. 같은 기간의 첫 번째와 두 번째 적격 주문 사이 간격을 1일 이내·1~7일·7일 초과로 나눕니다. 첫 구간은 24시간 이하, 가운데 구간은 24시간 초과 7일 이하입니다.
광고 후 결제 고유 시청자 → 후속 구매자 전환을 표시합니다. 예시 관찰기간은 최초 검증 시청 직후부터 7일입니다. 7일을 모두 관측한 고유 시청자 가운데 기간 안에 적격 구매를 마친 비율을 계산합니다. 팬덤과 직접 캠페인 범위 각각에 같은 분모·시간 규칙을 적용합니다. 광고와 구매의 선후 관계만으로 광고 효과를 확정할 수 없습니다.
국가·브랜드 국가별 팬 규모와 경제적 기여를 나란히 표시하고 타깃 시장 후보를 비교합니다. 구매 참여자 수, 확인된 유료 투표 단위, 금액 자료가 있는 순결제액을 개별 축으로 둡니다. 공급자·통화·환불 기준을 표시하고, 환율 출처와 기준일이 없으면 통화별로 분리합니다. 금액 자료가 없는 결제는 인원에만 반영합니다. 이 지표는 브랜드 제휴의 참고 자료이며 브랜드 가치 금액이나 예상 광고 매출은 별도 검증이 필요합니다.

무료 차트와 기업 리포트

기존 국가·기간 인기 순위, 개인·그룹 탐색, 공개 가능한 투표 통계는 무료 화면에 둡니다. 브랜드 담당자는 국가별 제휴 후보를 보다가 기존 기업 문의 페이지로 이동합니다. 팬 연령대·성별 분석은 수집과 이용 범위를 확인한 뒤 유료 리포트로 제공합니다. 직접 캠페인별 상세는 해당 캠페인의 리포트 접근 권한을 확인해 제공합니다. 기업 고객에게는 집계 수치만 전달합니다.

관리자 조회와 추출

운영자는 기간·국가·아티스트·그룹 집계 방식·광고/결제 범위·캠페인으로 필터링하고, 같은 조건의 집계표를 CSV로 추출합니다. 파일에는 통화·단위·분모·집계 시각을 포함합니다. 다운로드 시 서버가 관리자 권한을 다시 확인하고 조회 범위와 다운로드 사실을 기록합니다.

최고 유료 투표 기여자 ID는 관리자 상세 전용입니다. 확인된 유료 재화 사용량을 계정별로 합산한 뒤 순위를 매깁니다. 관리자·슈퍼관리자·활성 허용 목록·운영 역할과 테스트 계정은 순위 계산 전에 제외합니다. 동률이면 공동 1위로 처리합니다. 유료 사용 원천 미확인 상태에서는 순위를 발행하지 않습니다. 공개 화면·기업 리포트·일반 집계 CSV에는 개인 ID가 들어가지 않습니다.

현재 저장소에서 확인한 원천

지금 있는 자료로 새 집계를 만들 수 있는 지표

artist와 artist_group에는 표시 이름과 소속이 있고, artist_user_bookmark에는 즐겨찾기가 있습니다. vote_pick에는 대상, 사용자, 투표 시각과 재화별 사용량이 있습니다. purchase_reward_snapshots와 지급·환불 근거는 적격 구매자와 반복 결제 집계에 사용할 수 있습니다. 기존 공개 RPC는 기간별 순위와 시장 전체 추이를 제공합니다. 아티스트 활동 이력은 별도의 아티스트별 집계가 필요합니다.

새 수집 또는 연결 근거가 필요한 지표

ad_impressions의 발급·완료 시각 차이에는 대기·중단 시간이 들어갈 수 있습니다. 시청 시간은 실제 재생 구간을 수집한 뒤 표시합니다. ad_reward_events 및 공급자별 ad_reward_claims는 검증 상태와 중복을 확인한 범위만 집계합니다. 소스별 보상과 동일 노출의 연결을 확인할 수 없으면 채널별로 분리합니다. 직접 캠페인에는 아티스트 매핑, 전환에는 주문 연결, 시청 지역에는 이벤트 시점 국가, 유료 사용량에는 구매 재화 차감 근거가 각각 필요합니다.

Spotify 등 외부 지표

PICNIC 아티스트 ID와 공급자 아티스트 ID를 검증해 연결합니다. 지표에는 공급자·원래 지표명·단위·대상 국가·관측일·수집 가능 기간을 보존합니다. 확보 권한과 제공 범위가 확인된 지표부터 별도 시계열로 추가합니다. 앱 사용자 수와 외부 청취자 수를 더하지 않습니다. 이번 범위에는 Spotify 실데이터 수집이 포함되지 않습니다.

출시 전에 확인할 동작

  1. 한 그룹명과 멤버명으로 각각 검색해 그룹·개인 상세로 이동합니다. 순위 밖 카탈로그 대상과 동명이인도 확인합니다.
  2. 동일 팬이 멤버 두 명에게 투표해도 그룹 순 참여자는 한 명입니다. 직접 그룹 투표는 구분하고 기간 경계는 기존 완료 UTC 일자에 맞춥니다.
  3. 한 팬이 두 아티스트를 응원하고 구매했을 때 팬덤별 앱 활동의 중복 가능성을 표시합니다. 직접 캠페인은 검증된 연결에서만 구매를 셉니다.
  4. 시간 수집 전, 관측 기간 미완료, 분모 0, 금액 원천 누락은 자료 없음으로 구분합니다. 실제 집계 실패를 합성 수치로 채우지 않습니다.
  5. 소수 집단과 결제 기여량이 한 사람에게 집중된 경우에는 기존 공개 차트 보호 원칙을 확장 적용합니다. 검색·필터·추이·전환율·내보내기를 조합해 비공개 값이 드러나는지도 확인합니다.
  6. 로그아웃·일반 회원·기업 고객에게는 관리자 조회 및 추출 권한이 없습니다. 관리자 계정이 전체 유료 투표량 1위인 테스트에서도 권한 있는 운영자에게는 적격 일반 이용자만 나옵니다.

접근 권한과 데이터 준비 상태

지표 무료 공개 기업 운영 관리자
카탈로그·팬 수·투표 순위·추이 안전하게 발행된 집계 공개 집계 기간·대상·국가 필터
광고·반복 구매·후속 구매 안전하게 발행된 팬덤 집계 권한을 받은 캠페인의 집계 두 범위의 집계 및 CSV
국가별 순결제액·유료 사용량 미제공 권한 있는 캠페인과 검증된 단위·통화 검증된 원천만 조회·추출
최고 기여자 미제공 미제공 내부 user_id만 조회. 집계 CSV에서 제외

공개 셀은 고유 계정 10명 이상일 때만 발행합니다. 기여량 셀은 1인 최대 비중 20% 조건도 적용합니다. 기존 차트의 10단위 내림, 숨김 및 보완 억제를 재사용합니다. 신규 분할에서 차분 보호를 검증할 수 없으면 숫자를 공개하지 않습니다. 개인 정보 수집 이후의 연령대·성별은 기존 유료 리포트 범위입니다. 투자자용 합성 예시에는 모든 화면에서 시연 표식을 유지합니다.

팬덤 코호트는 특정 이벤트 직전 30일의 선택 대상 유효 투표 계정입니다. 그룹 직접·멤버 합산에는 선택한 방식만 적용합니다. 지표별 국가 출처에는 프로필 시장·검증 관측·미확인 상태를 기록합니다. 구매 시장은 선택한 팬 시장 기준을 명시하고 시청 위치와 구분합니다. 공동 캠페인에는 공유 표시를 붙입니다. 직접 주문은 광고 클릭/주문 간 연결을 검증한 자료만 인정합니다.

운영 전 검증 대상은 결제 재화의 차감 출처, 캠페인-주문 연결, 실제 시청 시간과 시청 국가입니다. 근거가 없는 과거 건은 미측정입니다. 부분·전액 환불과 관리자 승격 이후에도 오래된 값이 노출되지 않도록 다시 검증합니다. 추출은 수식 문자와 인용부호를 안전하게 처리합니다. 조회자·조회 조건·시각의 감사 로그는 내부 보관 정책에 따라 관리하며 이메일·영수증·응답 본문을 남기지 않습니다.

승인된 구현 순서

  1. DB 원천 수집. 전용 측정 마이그레이션에서 노출 소유자 검증과 누적 재생 시간의 멱등 기록을 구현합니다. 직접 캠페인 대상·주문 근거·구매 재화 원천은 쓰기 권한을 분리합니다. Flutter와 웹 플레이어에서 실제 재생과 일시정지·탐색·백그라운드 전환을 검사합니다.
  2. 조회 계약. 별도 보고서 마이그레이션에 카탈로그 검색, 팬덤 상세, 관리자 조회 RPC와 로컬 회귀 사례를 둡니다. 테스트에는 한 사용자의 팬덤 중복, 검증되지 않은 직접 캠페인, 환불, 역할별 접근을 넣습니다.
  3. 웹과 관리자. charts 진입점에서 검색과 상세로 이동하게 하고, 권한에 맞게 두 범위를 표시합니다. 관리자 화면에서는 같은 필터로 다시 권한을 확인한 후 집계 CSV를 내려받습니다. 외부 지표 확장에는 공급자 ID와 관측된 시계열의 출처를 보존합니다.
  4. 통합 검증. 격리 DB에서 실제 마이그레이션을 재생하고 프런트·RPC·모바일 흐름을 검증합니다. 운영 도메인과 DB 적용, 개인정보 고지 및 계측 활성화는 별도 출시 단계로 관리합니다.
