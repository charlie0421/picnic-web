4. 현재 경계

  • 제품 app·components·lib는 새 코드를 import하지 않는다. 제품 동작은 바뀌지 않았다.
  • 계약은 범위 A만 다룬다. upcoming·completed 목록, 더보기, filter, API 오류, popup의 DOM은 계약 밖이다. 이런 화면이 녹화되면 Replay가 schema로 종료된다.

6.2 envtest 빌드가 필요한 작업 — 빌드 재생성 필수

기존 envtest 빌드(.next-envtest, BUILD_ID WaMOsqHZc2V7cxWT91IY0)는 워크트리와 함께 삭제됐다. 생성기 재실행, 새 캡처, 원본 화면 비교에는 새 빌드가 필요하다.

  • 새 빌드는 새 BUILD_ID를 만든다. 그러면 fixture·manifest와 빌드가 맞지 않는다. 캡처를 다시 수집하고, fixture를 교체하고, 생성기로 manifest를 다시 만들어 검토해야 한다. manifest.test.ts의 기대 빌드 ID·해시도 바뀐다. 바꾼 이유를 결과 문서에 남긴다.
  • harness 사본: .superpowers/sdd/2026-10-16-vote-list-contract/(server.cjs, capture.cjs). 저장소 루트에서 실행한다. server.cjs --reuse-build는 옛 BUILD_ID를 고정 검사하므로 이제 쓸 수 없다. 옵션 없이 실행하면 다시 빌드한다.
  • 서버 포트는 53931(Next)·59862(upstream)이다. 다른 프로세스가 쓰고 있으면 종료하지 말고 멈춘다. 끝나면 server.json의 pid·nextPid만 종료한다.
  • Next가 tsconfig.json·next-env.d.ts를 바꿀 수 있다. 끝난 뒤 diff를 확인하고 source-snapshots.json으로 되돌린다.
  • 운영 Sentry DSN과 제품 .env를 쓰지 않는다.
node scripts/replay-p0/tools/build-css-manifest.cjs \

6.3 이번 작업에서 확인한 함정

  • styled-jsx wire 값은 CSSOM 문자열이다. textContent와 다르다. 생성기는 생성 CSSStyleSheet로 파싱한 값을 쓴다.
  • styled-jsx는 서버 HTML에 없다. client가 삽입한다. 생성기는 빌드 JS의 compiled style({id, dynamic, children})에서 text를 만든다. 동적 class는 styled-jsx 5.1.6 hash로 계산한다. styled-jsx 버전이 바뀌면 생성기가 멈춘다.
  • 복원 측정 전에 유한 CSS transition을 끝낸다. scroll 기록이 복원 도중 layout을 확정해 transition이 시작된다. 무한 animation은 그대로 둔다.
  • .vote-banner-section은 CSS 규칙이 없어 계약이 제거한다. 비교 selector는 main section을 쓴다.
  • 복원기의 placeholder 크기 변환은 img·svg·link에만 적용한다. P0 복원 동작을 바꾸지 않기 위해서다.
  • Codex 리뷰어 터미널은 첫 화면에 “Set up security” 선택지를 띄울 수 있다. Escape로 닫은 뒤 dispatch한다. 닫지 않으면 주입한 지시가 선택지에 먹힐 수 있다.
